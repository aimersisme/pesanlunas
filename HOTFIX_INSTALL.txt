PesanLunas v0.2.8 HOTFIX — untuk source v0.2.7

Cara pasang via GitHub Web:
1. Buka repository PesanLunas.
2. Upload seluruh isi folder hotfix ini ke ROOT repository (bukan folder hotfix-nya).
3. Jika GitHub meminta replace/overwrite, timpa file lama dengan file dari hotfix.
4. Commit langsung ke branch main.
5. Vercel akan redeploy otomatis.
6. Jalankan SQL patch v0.2.8 di Supabase SQL Editor satu kali:
   PesanLunas_v0.2.8_DASHBOARD_PERSONALIZATION_PATCH.sql

Hotfix ini hanya berisi file yang berubah dari v0.2.7 ke v0.2.8 (18 file source/assets/migration + petunjuk), sehingga aman untuk upload via GitHub Web dan tidak perlu mengunggah seluruh project.

Fitur yang dibawa:
- Sapaan Dashboard berdasarkan waktu + nama user yang login.
- Quote Dashboard dinamis/random dan editable dari Pengaturan Usaha.
- Tagline PesanLunas tampil di brand header.
- Logo transparan untuk auth/onboarding/dashboard/PWA.
- Tetap membawa Theme Engine v0.2.7 karena hotfix ini diterapkan di atas v0.2.7.
